# 冰菓·古典部推理

以《冰菓》（古典部系列）为蓝本的**日常推理**内容包。**非官方同人，版权归原作所有。**

## 怎么用（三步）

1. **装包**：设置页 → 插件 → 导入 `hyouka-1.0.0.dfplugin`
2. **启用**：在插件列表打开这个包的开关
3. **开玩**：创建游戏时选择「神山高中·古典部」世界与「古典部推理手册」规则

## 核心机制（推理靠脑力，骰子只给信息）

- **推理不掷骰**：玩家提出假设，GM 依据已收集线索判断正误——推理是玩家的脑力成果
- **骰子管信息**：观察/询问/记忆检定决定你能拿到多少细节、能否识破谎言
- **线索即道具**：旧杂志、占卜牌、料理记录、预告信——每条线索都能被调查、对比、组合
- **限时行动**：每个谜题有剩余天数，每天两个行动（调查/询问/整理/推理），天数耗尽谜题落幕
- **误导槽**：错误假设记入笔记，占线索位，需花行动点推翻——红鲱鱼是推理的一部分

## 内容清单

- **规则**：古典部推理手册（六维：观察力/记忆力/逻辑/知识/直觉/行动力 + 谜团进度/剩余天数）
- **世界**：神山高中·古典部，**20 条世界书自动进对局**（4 主角 + 入须冬实/十文字嘉保/本乡真由 + 6 场景 + 4 单元剧事件 + 《冰菓》主线 + 氛围）
- **角色卡**：折木奉太郎、千反田爱瑠、福部里志、伊原摩耶花
- **NPC**：入须冬实、十文字嘉保、本乡真由、善名姐妹、江波仓子、关谷纯
- **线索道具**：旧杂志《冰菓》、占卜牌、料理实习记录、『十文字』预告信
- **古典部特技**：节能主义、我很好奇！、数据库检索、真相之眼
- **职业**：节能侦探、好奇推手、知识库、毒舌监督

## 内置谜题（一个谜题 = 一场对局）

1. **广播室怪声事件**：门从里面反锁，声源却来自早已毕业的人——谜底藏在时间差里
2. **占卜游戏作弊**：连续猜中三次不是出千，是提问方式在泄露答案
3. **十文字偷窃预告**：失窃的不是财物，是各社团最珍视的『符号』
4. **预言剧本事件**：剧本精确预言现实——是巧合，还是有人按剧本行事？
5. **主线《冰菓》**：三十三年前，关谷纯独自承担了一切。『冰菓』读作 hyouka——Ice Cream，I scream

## 给 GM 的建议

- 谜题从日常小事里长出来：丢失的橡皮、改动的值日表、一句多说的话
- 推理对错不掷骰，但信息获取掷骰——玩家缺线索时会主动去调查，而不是等你说答案
- 误导证言是冰菓的灵魂：让 NPC 隐瞒、撒谎、误解，识破它们就是推理的一部分
- 真相揭示时，把收集到的线索逐条回放——那就是古典部的完美谢幕
